| `05-ratings-and-reviews.jpg` | Rating and review view |
| `06-secure-sign-in.jpg` | Account sign-in |
| `07-account-profile-redacted.jpg` | Account profile with portrait and personal fields blurred |

When adding new assets, use genuine current app captures where possible. Remove personal data, private owner details, credentials and exact private addresses before publishing.
